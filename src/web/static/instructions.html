🚀 How it Works (The Data Flow)

AudiobookNotes operates seamlessly in the background to capture quotes whenever you create a bookmark while listening on your Audiobookshelf server:

1. Bookmark Detection: The backend monitors active Audiobookshelf sessions and detects newly created bookmarks.
2. Audio Extraction: The server slices the audio around the bookmark timestamp (default: 20s before and 20s after).
3. Voice-to-Text: The audio fragment is transcribed using the fast Mistral Voxtral model on OpenRouter.
4. AI Quote Refinement: An LLM analyzes the transcription, isolates the exact literal quote spoken, determines the precision level, and provides its logical reasoning.
5. Saving & Visualizing: The results are saved locally in structured JSON files on your disk and displayed instantly on the dashboard.

✏️ Managing and Verifying Quotes

Confidence Ratings

Each quote displays a confidence badge (High, Medium, or Low) indicating the AI's estimation of literal accuracy compared to the raw transcription.

The Verification Mode ("Verify")

By clicking the elegant "✏️ Verify" button in the top-right of any quote card, the card expands instantly into a comprehensive workspace:

  • Quote Editing: Double click or focus on the text box to make manual corrections in case of transcription errors.
  • Original Transcription: Read the raw audio text transcript generated by Whisper.
  • LLM Extraction Reasoning: See the AI's step-by-step reasoning on why it isolated that specific quote.
  • Reprocess (+20% Audio): Trigger a single re-extraction if you suspect the quote was cut short. This will download a wider audio window, run Whisper again, and re-query the AI.
  • Auto-Promotion: Saving any manual edit (via "💾 Save") automatically elevates the confidence badge to High.

📥 Dual Exporters (Notion, Obsidian, Readwise)

AudiobookNotes provides section-specific downloaders inside each book's header section so you can easily import your notes into personal knowledge bases:

1. Scarica JSON

Downloads a clean, structured JSON file of the book containing quote arrays mapped with their exact audio positions (formatted as MM:SS or HH:MM:SS). Perfect for general scripting or customized database loading.

2. Scarica CSV Readwise

Downloads a custom CSV file tailored to match the exact format required for seamless import into the Readwise ecosystem:

  • Structure: Fully RFC 4180 compliant with headers: Highlight, Title, Author, URL, Note, Location, "Date".
  • Empty Fields: URL and Note columns are exported strictly empty ("") to maintain import cleanliness.
  • Location: Mapped with the audio timestamp in seconds represented as an integer (e.g. 2350).
  • Date: Bookmark date formatted strictly in UTC timezone as "YYYY-MM-DD HH:mm:ss" and wrapped in double quotes.
